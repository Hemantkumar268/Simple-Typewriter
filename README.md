# Simple Typewriter

A JavaScript typewriter animation that displays multiple phrases with dynamic typing and deleting effects.

## Features
- Animated typing and deleting
- Multiple rotating phrases
- Neon text glow with changing colors
- Pause and resume controls

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your browser.
